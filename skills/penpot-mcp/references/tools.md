# penpot-mcp tools

Generated from the server by `go test ./internal/tools -run TestSkillListsEveryTool -update`;
`TestSkillListsEveryTool` fails when this file and the server differ.

Route: **API** needs only the access token; **API + login** also needs
`PENPOT_EMAIL` and `PENPOT_PASSWORD`; **hybrid** runs on the API and adds a
step in the tab when one is connected; **tab** needs `PENPOT_MCP_URL` and a
connected Penpot tab with the file open.
