## In short

An MCP server in Go that drives Penpot through its backend HTTP API with a
personal access token, so an agent can read, draw into and manage any file
the token reaches without a browser tab. For the few things only a tab can
do (plugin code, reflow, CSS) it calls the official Penpot MCP. It ships as
a static binary through GitHub Releases and a Homebrew cask, carries its
own agent skills, and runs over stdio or HTTP.

## What a person can use

### Reading and navigating

- Teams, projects, files, pages, a compact page tree (with text content),
  single shapes and shape search by id, never an "active" file
  (`internal/tools/read.go`, `internal/tools/tree.go`; landed in
  `plans/01-first-version.md`, PR `#4`).

### Drawing and editing

- Rectangles, text sized with real font metrics, images, paths, groups,
  flex and grid layouts, and whole screens of up to 500 shapes in one call,
  plus edits and deletes (`internal/tools/draw.go`, `internal/tools/edit.go`,
  `internal/tools/layout.go`, `internal/fonts/fonts.go`; landed in
  `plans/02-drawing.md`).

### Dashboard and library

- Projects, files and pages created, renamed, moved and deleted
  (`internal/tools/dashboard.go`, `internal/tools/pages.go`;
  `plans/03-dashboard.md`).
- Colours, type styles, components, design tokens, and a palette pulled
  from the user's repository (`internal/tools/library.go`,
  `internal/tools/tokens.go`, `internal/palette/palette.go`;
  `plans/04-library.md`).

### Export and collaboration

- Boards to PNG, JPEG, WebP, SVG or PDF on disk, and whole `.penpot` files
  (`internal/tools/export.go`, `internal/penpot/exporter.go`;
  `plans/05-export.md`).
- Comments, share links, webhooks and saved versions
  (`internal/tools/comments.go`, `internal/tools/sharing.go`,
  `internal/tools/history.go`; `plans/07-collaboration.md`).

### The tab route, transport and accounts

- Plugin code, reflow, text measuring and CSS through the official MCP when
  `PENPOT_MCP_URL` is set and a tab is connected (`internal/mcproute/route.go`,
  `internal/tools/hybrid.go`; `plans/06-mcp-route.md`).
- `--http` serving the same tools at `/mcp`, refusing to bind off loopback
  without `PENPOT_MCP_HTTP_TOKEN` (`internal/httpserve/httpserve.go`;
  `plans/08-release.md`).
- Several accounts through `PENPOT_PROFILES` (`internal/config/profiles.go`;
  `plans/08-release.md`).

### Skills and install

- Five skills by job (`penpot-mcp`, `-draw`, `-library`, `-export`,
  `-collab`), embedded in the binary and written by
  `penpot-mcp skills install [--agent codex]` (`skills/`,
  `skills/install.go`; `plans/10-skills.md`, PR `#10`).
- Releases `v0.1.5` (20/10/2026) and `v0.1.6` (21/10/2026) with archives
  for darwin, linux and windows on amd64 and arm64, SBOMs, checksums and the
  `izam-mohammed/tap/penpot-mcp` cask (`.goreleaser.yaml`,
  `.github/workflows/release.yml`; `plans/08-release.md`).

## Under the hood

- **Shape**: `cmd/penpot-mcp/main.go` over `internal/` packages: `penpot`
  (API client and writer), `tools` (the 87 MCP tools, README "skills"),
  `transit`, `fonts`, `palette`, `mcproute`, `httpserve`, `config`.
- **Data**: none stored by the server; Penpot holds everything.
- **Integrations**: Penpot backend API, the official Penpot MCP, the Go MCP
  SDK, Claude Code and Codex skills, each documented in `docs/external/`;
  proof scripts in `scripts/prove/`.
- **Standards and CI**: `make check` (golangci-lint fmt and run, build,
  `go test -race`, govulncheck, gitleaks) per `docs/standards.md`, run by
  `.github/workflows/check.yml` on every push and PR. No coverage floor. The
  shared gate `izam-mohammed/.github` is not called. Actions are pinned by
  tag (`actions/checkout@v4`), not SHA.
